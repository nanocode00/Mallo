# 주문 시작 매장·포장 선택

## Why

- **페르소나**: 음성 주문을 시작하기 전에 이용 방식을 한 번만 명확하게 선택하려는 고령 사용자
- **상황**: 사용자는 키오스크를 시작한 직후 `매장에서 먹기` 또는 `포장하기`를 선택한다.
- **문제**:
  1. 매장·포장이 메뉴별 음료 옵션에 저장되면 같은 주문에서 값이 중복될 수 있다.
  2. 결제 직전에 처음 질문하면 주문 흐름이 끊기고 사용자가 선택을 놓칠 수 있다.
  3. 주문 취소 후 이전 이용 방식이 남으면 다음 사용자의 주문에 잘못 적용될 수 있다.
- **측정 지표**: 시작 단계 선택 성공률, 주문 중 선택값 보존률, 취소 후 초기화 성공률

## Goal

- **해결 목표**: 메뉴 주문 전에 매장·포장 중 하나를 선택하고 주문 전체 상태에 보존한다.
- **성공 기준**:
  - 앱 시작 시 메뉴 문장보다 이용 방식을 먼저 입력받는다.
  - 값은 `DINE_IN`, `TAKE_OUT` 두 가지만 허용한다.
  - 화면 버튼과 음성 선택을 모두 지원한다.
  - 메뉴 추가·장바구니 조회·주문 확정까지 같은 값이 유지된다.
  - 주문 전체 취소 시 이용 방식도 `null`로 초기화한다.
  - 기존 `OrderCommand[]` 의미 필드와 NLU 데이터셋 Label은 변경하지 않는다.
- **Out of Scope**:
  - 테이블 번호, 픽업 예상 시간, 배달 주소
  - 메뉴별로 서로 다른 이용 방식 지정
  - 결제·영수증·매장 좌석 관리
  - 실제 GUI 프레임워크와 터치 버튼 디자인

## What

### Happy Path

1. 앱이 `매장에서 드시나요, 포장하시나요?`라고 안내한다.
2. 사용자가 화면의 `[매장에서]` 또는 매장 표현을 말하면 `DINE_IN` Cart로 주문을 시작한다.
3. 사용자가 화면의 `[포장]` 또는 포장 표현을 말하면 `TAKE_OUT` Cart로 주문을 시작한다.
4. 장바구니 조회와 주문 확정 응답에서 선택한 이용 방식을 함께 안내한다.
5. 전체 주문을 취소하면 빈 Cart와 미선택 상태로 돌아간다.

### Edge Cases

| ID | 상황 | 처리 |
|---|---|---|
| EC-01 | 매장·포장 이외의 입력 | 선택 안내를 반복하고 주문 입력으로 넘어가지 않음 |
| EC-02 | 제품 주문 경로가 미선택 Cart로 메뉴 주문을 시도 | 주문을 실행하지 않고 매장·포장 선택 단계 유지 |
| EC-03 | 주문 처리 중 Cart 복사 | 이용 방식도 함께 복사 |
| EC-04 | 주문 전체 취소 | 이용 방식까지 초기화 |

## How

- `FulfillmentType`: `DINE_IN`, `TAKE_OUT`
- `Cart.fulfillment_type`: 주문 전체에 적용되는 nullable 값
- `MalloService.start_order(...)`: 검증된 이용 방식으로 빈 Cart 생성
- `src/app/main.py`: 메뉴 주문 입력 전에 이용 방식 선택
- `SessionState.to_dict()`: `cart.fulfillment_type` 직렬화
- `QUERY_CART`, `CONFIRM_ORDER`: 값이 있을 때 이용 방식 안내
- `CANCEL`: 새 `Cart()`를 반환해 메뉴와 이용 방식을 함께 초기화

터치와 음성은 동일한 `SET_FULFILLMENT` command를 Order Engine에 전달한다. 이용 방식은 메뉴 전후 어느 시점에나 설정할 수 있다.

## AC

### AC-01 · 매장 선택

- GIVEN: 새 앱 세션이 시작됐다.
- WHEN: 사용자가 매장 이용을 선택한다.
- THEN: 메뉴 주문 전에 `fulfillment_type=DINE_IN`인 빈 Cart가 생성된다.

### AC-02 · 포장 선택 보존

- GIVEN: `TAKE_OUT` Cart가 있다.
- WHEN: 메뉴를 추가하고 장바구니를 조회하거나 주문을 확정한다.
- THEN: Cart와 안내 응답에 포장 선택이 유지된다.

### AC-03 · 잘못된 시작 입력

- GIVEN: 이용 방식 선택 단계다.
- WHEN: 매장·포장 이외의 값을 입력한다.
- THEN: 주문 단계로 이동하지 않고 선택을 다시 안내한다.

### AC-04 · 전체 취소 초기화

- GIVEN: 이용 방식과 메뉴가 저장된 Cart가 있다.
- WHEN: `CANCEL`을 실행한다.
- THEN: CartItem과 이용 방식이 모두 초기화된다.

### AC-05 · 기존 NLU 계약 유지

- GIVEN: 기존 OrderCommand Schema와 파일럿 Label이 있다.
- WHEN: 매장·포장 선택 기능을 추가한다.
- THEN: OrderCommand 의미 필드 수와 데이터셋 Label 구조가 변하지 않는다.
