# AI Hub 친절체 script.id 분석

## 공개 범위

- 이 문서는 공개 저장소와 PR에 포함할 수 있도록 원본 대본과 대표 문장을 싣지 않는다.
- 원본 ZIP·WAV·JSON과 문장 단위 분석 자료는 AI Hub 다운로드 승인을 받은 이용자의 로컬 환경에서만 다룬다.
- 아래 결과는 원문을 복원할 수 없는 집계 통계와 범주 수준의 해석만 포함한다.
- 데이터 활용 사실: 과학기술정보통신부·한국지능정보사회진흥원 AI Hub 사업의 `감성 및 발화스타일 동시 고려 음성합성 데이터`(데이터셋 ID `71349`)를 활용했다.
- 기준 정책: [AI Hub 데이터 이용정책](https://www.aihub.or.kr/intrcn/guid/usagepolicy.do?currMenu=151&topMenu=105)

## 분석 기준

- 대상: 친절체 Training/Validation 라벨 ZIP 102개
- 현재 다운로드본: JSON 1,868개, 녹음 문장 88,777개
- `전체 문장`은 동일 대본을 여러 화자가 녹음한 레코드를 모두 포함한다.
- `고유 텍스트`는 동일 문구의 중복 녹음을 제거한 개수다. 원문 자체는 공개하지 않는다.
- `src_type`은 JSON 최상위 공식 라벨이다. 하나의 `script.id`에 둘 이상의 값이 존재하면 문장 수를 나누어 표시한다.
- `내용 기반 추정`은 로컬에서 원문을 검토해 사용 상황을 범주 수준으로 판정한 값이며 공식 라벨을 대체하지 않는다.

## 해석 및 PoC 적용

- 현재 다운로드본은 공식 통계의 89.69%이며, 파일 번호 누락분은 접근 가능한 자료만으로 원인을 확정할 수 없다.
- `script.id` 중 공식 `src_type`이 혼합된 항목이 있으므로 `script.id` 전체를 한 범주로 간주하면 잘못된 데이터가 섞인다.
- Fine-tuning 변환기는 레코드 최상위의 `src_type=매장응대`를 직접 검사해야 한다.
- `sub_style`의 `공감리액션`과 `공감 리액션`은 표기 차이로 관리하되, 현재 필터 조건에는 사용하지 않는다.
- 대표 문장 표는 공개 문서에서 제거했다. 추가적인 원문 검토가 필요하면 승인된 로컬 데이터에서 다시 산출하고 외부로 공유하지 않는다.
